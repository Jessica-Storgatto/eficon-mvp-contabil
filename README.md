# EFICON — Sistema de Gestão Contábil

MVP desenvolvido para a EFICON Contabilidade, com foco no controle de obrigações acessórias e centralização de documentos.

## Tecnologias
- Python 3.12
- Flask
- SQLite
- SQLAlchemy

## Como executar
pip install -r requirements.txt
python app.py

* Projeto em fase de desenvolvimento inicial.
